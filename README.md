# Structural and Functional Fidelity of Weighted Network Backbones

Replication of Pereira, Costa and Rocha (2026), *Distance backbones optimize spreading dynamics and centrality ranks in the
sparsification of complex networks* (arXiv:2603.14564v2), on two SocioPatterns contact networks (**hospital** and
**workplace1**), followed by an extension that explains why weight thresholding and the disparity filter lose spreading
fidelity and what distance backbones add.

Results, conclusion and limits: **[docs/RESULTS.md](docs/RESULTS.md)**. The base paper is in `papers/2603.14564v2.pdf`.

## Run everything
```
python -m pip install -r requirements.txt
python run.py            # complete pipeline from scratch, about 30 minutes; writes results/
python run.py --quick    # same code with 10 SI runs per seed, a few minutes; writes results_quick/
python -m pytest tests -q
```
`python run.py` is the only entry point; it also writes the dashboard data. Cached files in `results/` are reused; delete `results/` (or use `--force`) to start
from scratch. Options: `--networks hospital`, `--quick`, `--force`.

## Demo dashboard
After a full run, open `ui/index.html` in a browser (or `python -m http.server -d ui 8000`). Tabs: Overview, Network lens
(backbones at any size), Curves, AUC, Epidemic (SI simulated live), λ study, Sensitivity, Diagnosis, Extension, Conclusion.
`ui/data.js` is generated by `run.py` (`backbone/export.py`) from `results/`.

## What the pipeline does (per network)
1. **Replication:** five sparsification methods (W, DispFilt, wEffRes, SmD, DBS) compared on eigenvector-centrality rank
   (`ρ_C`) and SI spreading (`ρ_t`, `ξ⁻¹`), area under the curve, optimal DBS parameter, figures.
2. **Sensitivity:** β target, number of SI runs and the DispFilt weight normalisation.
3. **Diagnosis:** where centrality-rank and spreading fidelity disagree, the sparse regime, bridge retention.
4. **Extension:** connectivity fix (spanning tree), shortest-path test (metric backbone first), causal bridge test.

Outputs per network are in `results/<network>/` (CSV tables, `figures/`, `sensitivity/`, `diagnose/`, `extension/`) and the
cross-network tables in `results/summary/`.

## Layout
```
run.py                  the single entry point
backbone/
  data.py               contact files -> proximity / distance graphs; the two networks and the paper's Table 1 values
  backbones.py          semi-metric distortion, metric / ultrametric backbones, DBS lambda per edge
  sparsify.py           the five methods, progressive sparsification and the connected variants (+T, +R, +B, +X)
  sweep.py              eigenvector-centrality rank (rho_C) over every edge count; connectivity limits
  spread.py             SI model, rho_t and xi^-1_0.5, beta calibration
  summary.py            AUC, optimal lambda (Eq. 17)
  sensitivity.py        sensitivity settings and tables
  diagnose.py           diagnosis tables
  connected.py          the extension (three tests and their verdict rules)
  plots.py              figures
  export.py             results -> ui/data.js for the dashboard
ui/                     dashboard (index.html + data.js)
tests/                  pytest suite
data/                   the two raw contact files
docs/                   RESULTS.md (results, conclusion, limits)
papers/                 the base paper and Correia et al. 2023
```
Dependencies: numpy (2.0 or later), scipy, pandas, networkx, matplotlib, pytest.
